# Flow Local Test Runner for Chrome

Локальное расширение с запоминаемым переключателем и адаптивным патчем.
Окно DevTools не требуется.

Версия **3.1.0**.

## Установка

1. Закройте DevTools на вкладке Flow: одновременно подключиться может только один отладчик.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `E:\HeroSMS\flow-chrome-addon`.
6. Закрепите **Flow Local Test Runner** на панели инструментов.

## Использование

После установки режим включён автоматически и сохраняется между перезапусками
Chrome. Любая новая или восстановленная вкладка `flow.google.com` обрабатывается
сама. После обработки целевого JavaScript-файла отладчик сразу отключается.

Если Flow перенаправляет вкладку на адрес, заканчивающийся на
`/unsupported-country`, расширение автоматически возвращает её на
`https://flow.google.com/` и повторяет обработку. Защита от циклов останавливает
повторные перенаправления в течение 15 секунд и показывает `ERR`.

Иконка расширения работает как переключатель:

- режим `ON` — автоматическая обработка включена;
- нажатие переводит расширение в `OFF`;
- повторное нажатие включает `ON` и сразу открывает либо перезагружает Flow.

## Горячие клавиши

- `Alt+Shift+F` — включить/выключить расширение.
- `Alt+Shift+S` — открыть страницу состояния.

Страницу состояния также можно открыть через правый клик по иконке → **Параметры расширения**.

## Стратегии патча

Расширение пробует стратегии по порядку:

1. **known-field-accessor-exact-v2** — точный шаблон `_.uu(a,31)` или `_.pu(a,31)`.
2. **forced-callee-v1** — принудительно заданный вызов из настроек.
3. **adaptive-call-v1** — автоматический поиск переименованных вызовов с флагами `31`/`32`.
4. **route-guard-v2** — замена маршрут-гарда `if(!check())return"/unsupported-country"` на `if((check(),false))`.
5. **adaptive-single31-v1** — последний запасной вариант: единственный вызов с аргументом `31`.

На странице статуса видно, какая стратегия сработала.

## Страница состояния

Показывает:

- текущий режим (`ON`/`OFF`);
- время последней попытки;
- статус последней попытки;
- последний пропатченный URL;
- стратегию, которая сработала;
- последнюю ошибку;
- сохранённую диагностику.

На странице можно:

- включить/выключить автоматический режим;
- задать **принудительный вызов** (forced callee);
- скопировать или очистить диагностику.

## Статусы на иконке

- `ON` — автоматический режим включён и запомнен.
- `OFF` — автоматический режим выключен и запомнен.
- `RUN` — ожидается целевой файл.
- `OK` — точечная замена применена; через несколько секунд значок вернётся в `ON`.
- `ERR` — сборка не совпала или подключение не удалось. Наведите курсор на иконку,
  чтобы увидеть причину.

## Диагностика при сбоях

Если расширение показывает `ERR`, откройте страницу состояния (`Alt+Shift+S`) и
посмотрите сохранённую диагностику. В ней есть:

- список кандидатов с флагами `31` и `32`;
- фрагменты кода вокруг этих чисел;
- фрагменты вокруг `unsupported-country` и `age-restricted`;
- информация о маршрут-гардах;
- ошибки каждой стратегии.

Если автоопределение находит несколько кандидатов, скопируйте имя нужного из
диагностики и вставьте в поле **Forced callee**, затем нажмите **Save**.

Chrome показывает системную плашку об отладке только на время загрузки целевого
файла. После обработки подключение закрывается автоматически.
